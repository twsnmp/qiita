に機械学習でポーリング結果などの異常を検知する仕組みがあります。

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3874862/16300786-7c63-41cb-a8f0-ec58f85aa49f.png)

この処理のために

```
2024-1-1,元日
2024-1-8,成人の日
2024-2-11,建国記念の日
```

のような休みの日をCSVにしたデータを使っています。
毎年、自分でネット検索して更新してきましたが、今年はGeminiさんに

```
2026年に日本の休みを
2024-1-1,元日
2024-1-8,成人の日
2024-2-11,建国記念の日
2024-2-12,休日
2024-2-23,天皇誕生日
2024-3-20,春分の日
2024-4-29,昭和の日
のような形式で出力してください。
```

とお願いして作ってもらいました。数秒でやってくれました。

おかげで、かなり楽できました。
