# はじめに

ご自身のWebサイトやサーバー、あるいは社内のインフラのセキュリティ状態を「手軽に診断してみたい」と思ったことはありませんか？

一般的にセキュリティ診断を行うためのツール（`nmap` や `nuclei` など）は優秀なものが多いですが、多くがコマンドライン（CLI）ベースであり、非セキュリティ専門家や初心者にとっては以下のハードルがあります。

- インストールや依存ツールのセットアップが面倒
- コマンドのオプションが多くて使いこなすのが難しい
- 診断結果（ログやテキスト）を見ても、具体的にどう対策すればいいのかが分からない

これらの課題を解決し、**「誰でもボタン一つで簡単に診断でき、検出された脅威への対策までAIが優しく教えてくれる」** ツールを目指して開発したのが、AI搭載のデスクトップ・セキュリティスキャナー **[twSecScan](https://github.com/twsnmp/twSecScan)** です。

この度、最初のお試し版（v0.1.0）をリリースしましたので、その特徴や開発エピソードをご紹介します！

https://github.com/twsnmp/twSecScan

# twSecScan の特徴

`twSecScan` は、**Go言語 ＋ Wails ＋ Svelte** の構成で開発したデスクトップアプリケーション（GUI）です。

### 1. 外部ツールへの依存ゼロ（インストーラー不要）
従来のセキュリティツールの多くは、裏で外部のコマンドを実行する仕組みになっていますが、`twSecScan` は診断処理のすべてをGo言語で内製しています。そのため、面倒な外部ツールのインストールや環境構築の必要がなく、ダウンロードした実行ファイルを実行するだけでそのまますぐに動きます。

### 2. 直感的でわかりやすいGUI
Wailsを活用することで、HTML/CSS/SvelteによるモダンでクリーンなUIを実現しました。診断対象のURLやIPアドレスを入力し、実行ボタンを押すだけで診断がスタートします。

![twSecScan Dashboard](https://github.com/twsnmp/twSecScan/raw/main/images/ja/dashboard.png)

### 3. AIによる脅威の解説と対策アドバイス
スキャンで問題が検出された場合、内蔵されたAI機能（Ollamaを使用したローカルAI、あるいはOpenAIやAnthropicのAPI）と連携し、**「この脅威は何か」「具体的にどのような手順で修正・対策すればいいのか」** をステップバイステップでアドバイスしてくれます。

![twSecScan Findings & AI Advice](https://github.com/twsnmp/twSecScan/raw/main/images/ja/findings.png)

# 統合された9種類のスキャン機能

`twSecScan` は、1つのアプリケーションに以下の9つの強力なスキャン・分析機能を内蔵しています。

| # | 機能名 | 概要 |
|---|---|---|
| 1 | **OSINTスキャン** | 対象ホストのポートスキャンやDNSレコード情報の自動収集を行います。 |
| 2 | **Webクローラー** | サイト内の巡回を行い、リンク切れのチェックや、適切なセキュリティヘッダー（HSTS、CSP、X-Frame-Options等）のチェックを行います。 |
| 3 | **アセット監査** | 不用意に外部公開されている危険な設定ファイルやバックアップファイル（`.env`、`.git`、`backup.sql`など）の露出がないかを診断します。 |
| 4 | **入力値検証テスター** | フォームやパラメータに対し、簡易的なSQLインジェクションやクロスサイトスクリプティング（XSS）の脆弱性テストを行います。 |
| 5 | **技術スタック検出** | 対象のWebサーバー（Nginx、Apacheなど）やCMS（WordPressなど）、使用されているフレームワークを識別します。 |
| 6 | **APIファジング** | OpenAPI仕様書（Swaggerなど）を読み込ませることで、APIエンドポイントに対する動作検証や入力値チェックを自動で網羅テストします。 |
| 7 | **暗号設定検証** | SSL/TLS証明書の有効期限や暗号強度、SSHやメールサーバーの暗号化設定に脆弱な部分がないかを検証します。 |
| 8 | **ローカルフォルダ監査** | PC内の指定したローカルフォルダをスキャンし、パスワードや秘密鍵などの機密情報の露出リスク、不適切なパーミッション設定がないかを監査します。 |
| 9 | **AIによる対策アドバイス** | 各種スキャンで検出された問題点に対して、AIが対話形式で具体的な修正・対策方法をわかりやすく提案します。 |

# 開発の相棒「Google Antigravity」とアプリのアイコン作成

今回の `twSecScan` 開発では、仕様設計からプログラムの作成にいたるまで、AIコーディングアシスタントである **Google Antigravity 2.0（通称：Agy兄さん）** に大いにお手伝いしてもらいました。

その中でも、特に「楽で助かった！」と実感したのが **アプリのアイコン作成** です。

個人開発において、アプリの機能を作るのと同じくらい（あるいはそれ以上に）面倒なのが、グラフィック素材の用意です。
「それっぽいアイコンが欲しいけれど、デザインツールを立ち上げてイチから作るのも大変だし、フリー素材を探すのも時間がかかる……」

そこで、Google Antigravityに**「助手の猫さん（我が家の愛猫）の写真をベースにして、このセキュリティアプリにぴったりな格好いいアイコンを作って」**とお願いしたところ、アプリの持つ「スマートで安全なセキュリティ監査」という世界観にマッチした、素晴らしいアイコンが一瞬で生成されました！
